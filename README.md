# MEDIQ Project (GitHub Pages)

Upload all three files to the root of the same GitHub repository:
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — demo interactions

In GitHub Pages settings, select `Deploy from a branch`, branch `main`, folder `/ (root)`.

Important: This is a front-end prototype. Login, ambulance status, and other actions are demonstrations only. It does not contact emergency services, provide live ambulance GPS, or securely authenticate users. Do not enter real patient data.
